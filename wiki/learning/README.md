# Learning

Learning pages track paths, progress, review loops, open questions, and practice records.

Use this domain when the user is studying something over time.

Saved-for-later learning resources belong in a learning path's `Saved For Later` section when useful, but they do not count as progress until the user actually studies, practices, applies, or validates the topic.

Examples:

- Go learning
- Algorithms practice
- AI systems
- Economics reading
- Writing practice

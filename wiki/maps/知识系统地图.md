# 知识系统地图

## 怎么用

用这张地图理解这个 wiki 本身如何在“人类浏览、证据保存、agent 工作流”之间协作。

## 核心页面

- [[wiki/首页|首页]]
- [[wiki/maps/地图|地图]]
- [[wiki/tasks/任务|任务]]
- [[personal-llm-wiki|个人 LLM Wiki]]

## 当前线索

### 三层模型

- `sources/`：原始证据。
- `wiki/`：给人和 agent 阅读的编译知识。
- `todo.md` + `wiki/tasks/`：个人任务执行面板和结构化任务库。
- `system/`：工作流、schema、模板和检查规则。

### 人类浏览

- 从 [[wiki/首页|首页]] 开始。
- 用 [[wiki/maps/地图|地图]] 做可视化导航。
- 领域 README 只在需要看目录说明时打开。

### Agent 操作

- 查询路由从 `index.md` 开始。
- 用 `system/resolver.md` 判断 workflow 和 domain。
- 用各 domain 的 `AGENTS.md` 判断页面 schema。
- 用 `system/evals/ingest-checklist.md` 审计 ingest。
- 用 `system/evals/task-checklist.md` 审计 task capture / update。

## 维护

- 操作规则放在 `system/`，不要放在地图页。
- 地图页只做导航，不复制大段总结。
- wiki 操作模型变化时，更新这张地图。

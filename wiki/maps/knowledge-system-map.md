## Current Threads

### Three-Layer Model

- `sources/`: original evidence.
- `wiki/`: compiled knowledge for humans and agents.
- `system/`: workflows, schemas, templates, and evals.

### Human Browsing

- Start at [[wiki/home|Obsidian Home]].
- Use [[wiki/maps/maps|Maps]] for visual navigation.
- Use domain README pages for scoped browsing.

### Agent Operation

- Start at `wiki/index.md` for query routing.
- Use `system/resolver.md` to choose workflow and domain.
- Use domain `AGENTS.md` files for page schemas.
- Use `system/evals/ingest-checklist.md` to audit ingest work.

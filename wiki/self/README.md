# Self

Self pages are compiled identity and self-understanding views.

Use this domain for:

- self portraits
- identity snapshots
- values and drivers
- recurring personal operating patterns
- pressure and recovery patterns
- current direction summaries

This domain should synthesize from source-backed pages such as people, events, themes, reflections, projects, and tasks. It is not a source layer and should not replace those canonical pages.

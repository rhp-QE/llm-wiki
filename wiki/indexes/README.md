# Indexes

Indexes are lookup surfaces for fast retrieval. They sit between the agent routing page (`wiki/index.md`) and the domain pages.

Use this domain for:

- Entity and page lookup
- Alias lookup
- Timeline lookup
- Source manifests
- Generated indexes by task, project, learning path, or report type

Indexes should link to canonical pages and source paths. They should not become a second source of truth.

Start with [索引](索引.md).

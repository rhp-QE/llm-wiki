# Projects Schema

## Contract

Project pages should make state and next actions clear.

## Frontmatter

```yaml
---
type: project
title:
status: idea | active | paused | done | abandoned
started:
updated:
tags: []
---
```

## Body

```markdown
## Goal

## Current State

## Context

## Decisions

## Tasks

## Related Knowledge

## Log
```

## Anti-Patterns

- Do not convert every idea into a project.
- Do not hide stalled status; mark it explicitly.

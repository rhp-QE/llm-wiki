# 首页

这是在 Obsidian 里浏览 LLM-wiki 的入口页。

Agent 路由和系统状态看 `index.md`。日常可视化浏览先从地图开始。

## 从这里开始

- [地图](maps/地图.md)：可视化导航入口。
- [索引](indexes/索引.md)：实体、别名、时间线和来源等快速检索入口。
- [任务](tasks/任务.md)：任务索引和进度快照。

## 主要领域

如果 Obsidian 没有隐藏 README，可以在文件浏览器里看这些领域说明：

- `people/README.md`：人物
- `events/README.md`：事件
- `themes/README.md`：主题
- `projects/README.md`：项目
- `tasks/README.md`：任务
- `learning/README.md`：学习
- `tech/README.md`：技术
- `qa/README.md`：问答
- `craft/README.md`：工程实践
- `models/README.md`：思维模型
- `reflections/README.md`：反思
- `writing/README.md`：写作
- `reports/README.md`：报告

## 当前状态

- 这是一个空框架分支。
- 真实源材料、真实人物、真实事件、真实项目、真实任务和真实学习进度已从工作树移除。
- 新内容应先进入 `inbox/` 或 `sources/`，再通过显式 ingest 写入 `wiki/`。

## 图谱过滤

推荐 Obsidian Graph filter：

```text
-path:AGENTS -path:README -path:index -path:log -path:logs
```

## 维护规则

- 这个页面保持短，主要服务日常浏览。
- 新增重要地图时，在这里加链接。
- 领域 README 负责说明目录；地图页负责串联跨领域关系。

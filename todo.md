# Todo

This is the active task dashboard for the personal LLM-wiki.

Canonical task records live under `wiki/tasks/`. Use this file for quick execution and review; keep task details, source, and history in task pages.

Task Granularity Gate: lightweight one-off todos may stay here as plain checkboxes when they have no due date, waiting/blocking state, durable context, or clear linked page. Serious tracked tasks should link to canonical task pages under `wiki/tasks/`. Multiple small todos with one shared goal should usually become a checklist inside one parent task.

Direct commands such as `给我记一个 todo` should apply the Task Granularity Gate, then add either a lightweight checkbox here or a linked canonical task item.

Task index for Obsidian: `wiki/tasks/任务.md`.

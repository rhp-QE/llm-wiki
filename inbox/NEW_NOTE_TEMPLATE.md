# New Note Template

Copy this file when dropping new material into `inbox/`.

```markdown
# {Title}

Date: YYYY-MM-DD
Type: learning | diary | article | idea | project | qa | reflection | other
Source: URL or original location if any

## Raw Note

Write the note here. It can be messy.

## Why It Matters

Optional. Why you want to remember this.

## Questions

Optional. What is still unclear?

## Suggested Targets

Optional. For example:

- Go learning
- Writing idea
- Personal reflection
- Person / event / theme
```

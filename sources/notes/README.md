# Note Sources

Archive miscellaneous or ambiguous source material here when no more specific source directory owns it.

Use this directory for:

- URL-backed material whose content form cannot be confidently classified.
- Small captured notes that are not diary, learning, article, chat, media, project, Q&A, or reflection.
- Source material marked `source_type: note` with `status: needs-review`.

Do not route ambiguous notes to `sources/diary/` without an explicit `diary` / `日记` marker. Do not route URL-backed notes to `sources/learning/` merely because the user may learn from them.

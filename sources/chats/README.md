# Chat Sources

Archive useful conversation excerpts here.

URL-backed chat records or conversation exports belong here after explicit Ingest when their content can be preserved or the user provided enough context. Keep the original URL in frontmatter when available.

If the user marks a chat as `important`, `importent`, `非常重要`, `重要`, or equivalent, preserve the core information carefully. For short chats, fuller excerpts may be appropriate. For very large chats, do not save the whole transcript by default; save a core extraction capped at 500 Chinese characters plus selected message IDs, timestamps, speaker names, or other anchors that make the extraction traceable.

Use when a discussion produced:

- A reusable answer
- A decision
- A personal insight
- A technical explanation
- A future follow-up

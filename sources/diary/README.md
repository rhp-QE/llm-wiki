# Diary Sources

Personal diary and life notes go here.

Diary routing requires an explicit marker. A source may be stored here only when the raw material, inbox metadata, title, filename, or user instruction contains `diary` / `日记`, such as `Type: diary`, `source_type: diary`, or "按日记处理".

Do not classify a source as diary from emotion, routine, first-person writing, or "today" alone. Untyped ambiguous fragments should be stored as `source_type: note` with `status: needs-review` outside `sources/diary/` until the user confirms.

The compiled layer may update:

- `wiki/people/`
- `wiki/events/`
- `wiki/themes/`
- `wiki/models/`
- `wiki/reflections/`

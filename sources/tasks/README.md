# Task Evidence Sources

This directory stores source-worthy evidence for long-term tasks and meaningful task execution history.

Use this directory when a task or task update records durable evidence:

- Long-term, ongoing, recurring, routine, habit-forming, important, or review-worthy goals.
- Meaningful check-ins with observations.
- Milestones, substantial progress, repeated practice, blockers, failures, missed routines with reasons, unblock conditions, abandonment reasons, completion outcomes, or weekly/monthly reviews.
- Project, learning, health, career, relationship, or life history that future agents should be able to rebuild from sources.

Do not use this directory for:

- Lightweight one-off todos.
- Dashboard ordering or cleanup.
- Mechanical status changes with no context.
- Typo fixes or priority changes without durable reason.
- Daily done/not-done checkboxes with no user-provided observation.

For repeated check-ins on one long-term task, prefer a grouped monthly source file and preserve each update as a separate fragment with timestamp, origin, and original wording.

Suggested path patterns:

- `sources/tasks/YYYY/YYYY-MM-DD-{task-slug}-{event}.md`
- `sources/tasks/YYYY/YYYY-MM-{task-slug}.md` for grouped monthly check-ins
